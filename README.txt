Roadie Admin - Training Environment
Release 1 Proof of Concept

Open index.html in a modern browser. No installation, server or internet connection is required.

Release 1 demonstrates:
- An Admin-first training environment using fictional data
- A training shift dashboard rather than scenario selection
- A persistent active customer case beside Admin
- Global Search and fictional driver profile investigation
- Training-safe account actions and profile notes
- Case details, case notes and customer response requirements
- Optional progressive coaching and a knowledge quick guide
- Case-level XP, support readiness and streak feedback

Suggested proof-of-concept flow:
1. Start the training shift.
2. Accept the waiting driver contact.
3. Use the customer's phone number in Global Search.
4. Review the three related driver profiles.
5. Mark TRN-ACC-001 as primary and unlock it.
6. Leave duplicate profiles locked and clear their license information.
7. Add relationship notes to the primary and both duplicate profiles.
8. Complete the case details and case notes in the Active Case panel.
9. Send a clear response to the customer.
10. Close the case and review the coaching summary.

All names, IDs, customer records and actions are fictional. Nothing connects to Roadie production systems.
